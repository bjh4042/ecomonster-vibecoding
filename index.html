🔒 명단은 이 브라우저에만 저장되고 어디로도 보내지 않아요. 요청을 보낼 때 이름을 학생A, 학생B…로 바꿔 보내고, 결과를 받으면 다시 실명으로 되돌려 보여 줘요.
🔒 학생 개인정보 업무는 꺼져 있어요 — 생기부 문장·상담 기록·관찰 기록 버튼과 분류가 숨겨지고, 그런 요청은 보내기 전에 막아요.
💻 게임 저장소 현황 (Claude Code 연동) 게임 저장소의 Claude Code 작업 현황을 사무실에 띄워요 (공개 저장소)
게임 저장소에서 Claude Code가 status.json을 갱신하게 하면, 할 일과 진행률이 사무실 캐릭터에 그대로 나타나요.
토큰은 GitHub → Settings → Developer settings → Fine-grained tokens에서 그 저장소 하나만 고르고 Contents: Read-only, (이슈로 보내기를 쓰려면) Issues: Read and write만 주세요. 이 브라우저에만 저장돼요.
