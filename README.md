# AI 오피스 — 바이브코딩팀 & 교무팀

서버 없이 동작하는 웹앱입니다. GitHub Pages: https://bjh4042.github.io/ecomonster-vibecoding/

## 팀 구성
**💻 바이브코딩팀** (생태몬스터 게임)
- 게임 기획 · 개발자 · QA 테스터 · 코드 리뷰
- 아이디어 회의: 기획 → 개발(구현 난이도) → QA(원작 유사성·밸런스) → 리뷰(우선순위) → 최종 정리 + Claude Code 작업 지시문
- 실제 코드 작업은 Claude Code 담당. 이 팀은 아이디어·검토용

**🏫 교무팀** (초등 교사 업무)
- 수업 담당(새싹) / 생활지도(고슴도치) / 학부모 소통(토끼) / 행정 담당(거북이) / 업무 비서(다람쥐)
- 요청을 업무 비서가 자동 분류해 담당자에게 배정 → 초안 → 동료 검토 → 최종본 (빠르게 모드는 담당자만)

**캐릭터**: 거제 생태 몬스터 콘셉트로 직접 그린 픽셀 캐릭터
- 바이브코딩팀: 기획(동백새) · 개발자(몽돌) · QA(꽃게) · 리뷰어(해파리)
- 담임(나): 부엉이

**화면 조작**: 끌어서 이동 · 마우스 휠로 확대/축소 · 두 번 눌러 전체 보기

## 새 기능 (3)
- **자주 쓰는 업무 버튼**: 교무팀 — 알림장·가정통신문·주간학습안내·생기부 문장·상담 기록·수업 지도안·계획서/공문 / 바이브코딩팀 — 몬스터·맵·대사·밸런스. 아는 칸만 채우면 요청문이 만들어지고 담당자도 자동 지정
- **이어서 고치기**: 결과 아래 "더 짧게" 같은 한 줄 → 담당자가 한 번만(Gemini 1회) 고쳐서 완료함에 따로 저장
- **🐙 Claude Code에 이슈로 보내기**: 아이디어 회의 결과의 "작업 지시문"만 뽑아 게임 저장소 GitHub 이슈로 올림 → Claude Code에 붙여 넣을 한 줄도 만들어 줌 (토큰에 Issues 쓰기 권한 필요)

## 새 기능 (2)

- **활동별 장소**: 자료 볼 때 책장·칠판(📖) → 책상에서 작성(✏️), 검토는 회의 탁자(🔍)
- **잡담**: 한가한 캐릭터끼리 근처에 있으면 미리 써 둔 대사로 대화 (API 안 씀)

- **사용량**: 오늘 Gemini 호출 횟수, 작업별 예상 호출 수, 하루 한도 설정

## 새 기능
- **두 팀 동시 진행**: 교무팀이 일하는 중에도 바이브코딩팀에 요청 가능 (팀별 진행률을 합쳐 표시)
- **학생 이름 가리기**: [맥락 → 학생 명단]에 이름을 넣으면 보내기 전에 학생A·학생B로 바꾸고, 결과는 실명으로 되돌림(조사 '와/과, 는/은'도 맞춤). 명단은 브라우저에만 저장
- **한글(HWPX) 받기**: 결과를 바로 .hwpx로 (제목·소제목·목록·표·굵게 유지). `lib/hwpx.js`
- **서식 복사**: 표·굵게를 유지한 채 복사 → 한글/워드/메일에 붙여넣기
- **단계별 내용 보기**: 대화 카드의 "▾ 내용 보기"로 각 담당자의 초안·검토 전문 확인
- **기록 백업**: 백업 파일 받기/불러오기 (학교 PC ↔ 집 PC)
- **캐릭터 카드**: 캐릭터를 누르면 역할·상태·최근 결과
- **완료 알림음 + 다른 탭에 있을 때 브라우저 알림**
- **길찾기**: 캐릭터가 벽·가구를 피해 문으로 다님, 가구 뒤에 가려짐
- **두 손가락 확대**(휴대폰), **비공개 저장소 토큰**(현황 탭)

## 탭
- **작업**: 팀 선택 후 요청. [시연 보기]는 API 호출 없이 동작만 보여 줌
- **현황**: 게임 저장소(공개)의 최근 커밋과 `status.json`을 읽어 사무실에 표시. 3분마다 새로고침
- **API 키**: Gemini 키 저장, 모델 목록 불러오기, 연결 테스트
- **맥락**: 학교 맥락 / 게임 맥락 (에이전트가 읽는 배경 정보)
- **기록**: 최근 30개 결과, .md 받기

## Claude Code 연동 (현황 탭)
[현황] 탭의 "Claude Code에 붙여넣을 안내문 복사" → 게임 저장소에서 작업 중인 Claude Code에 붙여 넣기.
그러면 Claude Code가 `status.json`을 갱신하고, 그 내용이 사무실 캐릭터와 진행률에 나타납니다.
이 저장소의 `status.json`이 예시입니다.

## 모델 오류 대처 (자동)
- 404 "모델 없음": 안내된 새 모델로 자동 변경
- 503 "서버 혼잡": 잠깐 쉬고 재시도, 계속되면 다른 flash 모델로 대신 호출
- 429 "호출 한도": 15초 이상 쉬고 재시도
