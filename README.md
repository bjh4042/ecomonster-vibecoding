## 팀 구성 — 생태몬스터 바이브코딩팀 (디렉터: 나)
MetaGPT(PM→아키텍트→엔지니어→QA), ChatDev(설계→코딩→테스트), Claude Code 서브에이전트 팀(Planner·Coder·Reviewer·Tester), 게임 스튜디오형 구조(디렉터·리드·전문가)를 참고했어요.

**🎨 기획 파트** — 게임 내용·설계 문서
- PD(다람쥐): 요청 배정, 작업 쪼개기, 로드맵·범위·일정
- 게임 기획(동백새): 몬스터·맵·전투·밸런스
- 생태 고증(새싹): 실제 생물·지역 사실 확인, 도감 설명
- 시나리오(토끼): 스토리·대사·퀘스트
- 아트·UI(거북이): 도트 규격·팔레트·화면 배치·반응형

**🛠 개발 파트** — Claude Code에 넘길 지시문·설계·점검
- 아키텍트(고슴도치): 구조·데이터·세이브 설계, 공통 엔진
- 개발자(몽돌): Claude Code 지시문
- QA(꽃게): 테스트 체크리스트·버그 재현
- 리뷰어(해파리): 교정·리팩터링 계획

**흐름**: 요청 → 자동 배정 → 초안 → 동료 검토 → (내 확인) → 최종본 → 🛠 개발 파트로 넘기기 → Claude Code 지시문 → 두 번 확인 후 넘기기. 두 파트는 동시에 일할 수 있어요.
**팀 규칙**: 설정 → 📏 팀 규칙 (모든 담당이 지켜요). 게임 맥락은 게임 프로젝트마다 따로.

**화면 조작**: 끌어서 이동 · 마우스 휠로 확대/축소 · 두 번 눌러 전체 보기

## 새 기능 (10) — 무료 한도 안에서 효율적으로 (Gemini 전용)
- 💰 아끼기 모드(기본 켬): 동료 검토는 가벼운 모델(flash-lite)로 보내 주력 모델 한도를 아끼고, 검토가 "판정: 통과"면 최종 단계를 건너뜀 (호출 1회 절약)
- 무료 한도는 모델마다 따로라서 주력·가벼운 모델을 나눠 쓰면 하루에 더 많이 일할 수 있음
- 한도 관리: 오늘 쓴 호출을 모델별로 셈(한국 오후 5시, 여름엔 4시 초기화), 하루 한도에 걸리면 바로 다른 모델로 이어서 함, 분당 한도는 알려 준 시간만큼만 쉼, 같은 모델은 6.5초 간격으로 보내 분당 한도 예방
- 업무 유형마다 정해진 결과 형식(표·목록)으로 써서 고쳐 쓰는 일을 줄임, 서론·맺음말 금지, 게임 맥락·팀 규칙은 길면 잘라서 보냄

## 새 기능 (9) — 실제 작업이 보이는 사무실
- 📡 게임 저장소의 새 커밋을 담당이 대화로 알려 줘요 (예: 개발자 → QA "「버그 수정」 올렸어요"). status.json의 진행 중 작업은 그 담당이 자리에서 일해요
- 🚀 출하장(옛 배포실) 벽에 GitHub Pages 배포 횟수, 새 배포가 생기면 PD가 알려 줘요
- Claude Code로 넘기는 지시문 끝에 "status.json 진행 보고" 문구가 자동으로 붙어요 (넘기기 1단계에서 지울 수 있음)
- 🎨 게임마다 다른 사무실: 거제도 제작소(동백·소나무, 초록 잔디) / 대한민국 제작소(은행·단풍, 가을 잔디), 제목·부제도 바뀜
- 🏆 만든 것 전시: 완료한 작업과 완료함 결과가 휴게실 바닥 이름표로 놓이고, 누르면 열려요

## 새 기능 (5) — Claude Code로 넘기기
- 바이브코딩팀 **🤖 Claude Code 지시문** 모드: 대충 적은 요청을 개발자(Gemini 1회)가 목표·할 일·건드릴 곳·완료 조건·확인 방법·주의 형식으로 다듬음
- 결과 아래 **[🤖 Claude Code로 넘기기]** → 1) 보낼 내용 확인·수정 → 2) 받는 대화창 고르기(이름 붙여 저장, GitHub 이슈도 선택 가능) → 3) **"넘기겠습니까?"** 마지막 확인
- 확인하면 내용이 복사되고 그 대화창이 새 탭으로 열림 → 붙여넣기(Ctrl+V) 후 보내기 (자동 전송은 하지 않음)
- 완료함 위에 **넘긴 기록** (다시 복사·열기·보기)
- **교정 단계**: 개발자 초안 → 리뷰어 교정 검토(애매한 표현·빠진 완료 조건·범위 초과·위험한 지시·게임 맥락 충돌) → 반영 최종본 + 교정 반영 내역 (Gemini 3회, '만들기만' 1회도 선택 가능)
- 결과 아래 **[🔍 다시 교정]**, 넘기기 1단계에서 직접 고친 뒤 **[🔍 AI로 다시 교정]** + **[↩ 되돌리기]**. 넘길 때는 교정 반영 내역을 빼고 지시문만 보냄

- **길찾기**: 캐릭터가 벽·가구를 피해 문으로 다님, 가구 뒤에 가려짐
- **두 손가락 확대**(휴대폰), **비공개 저장소 토큰**(현황 탭)

## Claude Code 연동 (현황 탭)
[현황] 탭의 "Claude Code에 붙여넣을 안내문 복사" → 게임 저장소에서 작업 중인 Claude Code에 붙여 넣기.
그러면 Claude Code가 `status.json`을 갱신하고, 그 내용이 사무실 캐릭터와 진행률에 나타납니다.
이 저장소의 `status.json`이 예시입니다.

## 모델 오류 대처 (자동)
- 404 "모델 없음": 안내된 새 모델로 자동 변경
- 503 "서버 혼잡": 잠깐 쉬고 재시도, 계속되면 다른 flash 모델로 대신 호출
- 429 "호출 한도": 15초 이상 쉬고 재시도
