서버 없이 동작하는 웹앱입니다. GitHub Pages: https://bjh4042.github.io/ecomonster-vibecoding/

## 팀 구성
**💻 바이브코딩팀** (생태몬스터 게임)
- 게임 기획 · 개발자 · QA 테스터 · 코드 리뷰
- 아이디어 회의: 기획 → 개발(구현 난이도) → QA(원작 유사성·밸런스) → 리뷰(우선순위) → 최종 정리 + Claude Code 작업 지시문
- 실제 코드 작업은 Claude Code 담당. 이 팀은 아이디어·검토용

**🏫 교무팀** (초등 교사 업무, 「AI 교무실」 캐릭터)
- 윤슬: 수업·활동지·평가 / 예준: 생활지도·상담 / 수아: 학부모 소통·기록 / 태윤: 공문·행정·행사 / 하람: 비서·업무관리
- 요청을 하람이 자동 분류해 담당자에게 배정 → 초안 → 동료 검토 → 최종본 (빠르게 모드는 담당자만)

## 탭
- **작업**: 팀 선택 후 요청. [시연 보기]는 API 호출 없이 동작만 보여 줌
- **현황**: 게임 저장소(공개)의 최근 커밋과 `status.json`을 읽어 사무실에 표시. 3분마다 새로고침
- **API 키**: Gemini 키 저장, 모델 목록 불러오기, 연결 테스트
- **맥락**: 학교 맥락 / 게임 맥락 (에이전트가 읽는 배경 정보)
- **기록**: 최근 30개 결과, .md 받기

## Claude Code 연동 (현황 탭)
[현황] 탭의 "Claude Code에 붙여넣을 안내문 복사" → 게임 저장소에서 작업 중인 Claude Code에 붙여 넣기.
그러면 Claude Code가 `status.json`을 갱신하고, 그 내용이 사무실 캐릭터와 진행률에 나타납니다.
이 저장소의 `status.json`이 예시입니다.

## 모델 오류 대처 (자동)
- 404 "모델 없음": 안내된 새 모델로 자동 변경
- 503 "서버 혼잡": 잠깐 쉬고 재시도, 계속되면 다른 flash 모델로 대신 호출
- 429 "호출 한도": 15초 이상 쉬고 재시도
